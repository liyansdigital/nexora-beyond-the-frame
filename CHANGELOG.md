# Changelog

All notable changes to NEXORA are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/), and the project uses
[Semantic Versioning](https://semver.org/).

## [1.0.0] — 2026-11-15

Initial public release.

### Added

- Cinematic dark-glass skin for the Video.js v10 HTML renderer (`@videojs/html` 10.4.0)
- Floating control dock with aurora-gradient timeline, chapter markers and titles
- Storyboard thumbnail previews on the time slider
- Glass settings menu (speed, quality, audio, subtitles) and volume popover
- Centre play disc, buffering indicator, styled error dialog
- Captions layer with English/Japanese demo tracks
- PiP, fullscreen, AirPlay and Cast controls where the platform supports them
- Full keyboard operation, visible focus, live-region status announcer
- Reduced-motion support via `prefers-reduced-motion`
- Responsive layout for desktop and mobile
- Preview workbench (`apps/preview/`) with a live Mux-hosted demo
- Documentation: README, ARCHITECTURE, CONTRIBUTING, SECURITY, SUPPORT and docs/
