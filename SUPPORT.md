# Support

## Getting help with NEXORA

- **Questions about using or customising the skin** — open a GitHub issue
  using the feature/question template, or start with the docs:
  [README](README.md), [ARCHITECTURE](ARCHITECTURE.md),
  [Customization](docs/customization.md),
  [Troubleshooting](docs/troubleshooting.md).
- **Bugs** — use the bug report template and include your browser and steps
  to reproduce.
- **Security issues** — see [SECURITY.md](SECURITY.md); do not file public
  issues for vulnerabilities.
- **Video.js itself** — player-core questions belong to the
  [Video.js project](https://github.com/videojs/video.js); NEXORA only covers
  the skin in this repository.
